# 屿声映画 · 高保真交互原型

这是屿声映画 V1 的静态交互原型，包含 24 个页面，可用于产品评审与体验演示。

在线体验：https://wyf10171.github.io/yusheng-prototype/

## 体验

站点入口为 `index.html`，支持桌面和手机浏览器。所有页面使用相对路径，可直接部署到 GitHub Pages 的项目站点。

主要体验路径：

- 声音工作台 → 音色选择 → 演示生成 → 发布 → 我的作品。
- 接单大厅 → 需求详情 → 试音提交 → 候选人选择 → 订单交付与验收。
- 学院 → 课程详情 → 演示购买 → 学习 → 作业提交与点评。
- 声播 → 直播间 → 示例收听、聊天与礼物演示。

## 演示范围

人物、订单、课程和收益均为虚构示例。AI 生成、付款、直播及审核使用本地模拟流程，不提供真实交易或服务端处理。录音依赖浏览器麦克风授权；上传的文件仅在当前浏览器内预览，不会传至服务器。

演示状态存储在当前浏览器的 localStorage 中，不会在访问者之间共享，可在设置页重置。

## GitHub Pages

发布目录为本仓库根目录，无需构建。上传到 GitHub 后，在 Settings → Pages 中选择 Deploy from a branch，并将发布源设为 `main` 分支的 `/ (root)`。

`.nojekyll` 用于直接发布静态文件。实际分享地址以 GitHub Pages 部署成功后返回的地址为准。

## 本地维护

直接打开 `index.html` 即可体验。需要重新生成页面时：

```sh
npm ci
node 构建.cjs
```

`说明.md` 包含更完整的页面清单、实现边界和素材信息。Lucide 图标许可保留在 `vendor/LICENSE.lucide`。

浏览器验证使用本机 Microsoft Edge，执行 `node 验证/浏览器验证.cjs`。默认验证本地页面；设置环境变量 `BASE_URL` 可验证线上站点，`TEST_PROXY` 可指定浏览器代理。
